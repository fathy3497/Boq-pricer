# BOQ Auto Pricer 📊

Web app لتسعير مقايسات البناء (BOQ) تلقائياً بالذكاء الاصطناعي.

## الميزات
- ارفع أي ملف BOQ Excel
- يكتشف البنود تلقائياً من أي هيكل
- يسعّر بـ Gemini AI (مجاني)
- يدعم SAR / EGP / AED / USD
- حمّل النتيجة Excel

## تشغيل محلي
```bash
pip install -r requirements.txt
streamlit run app.py
```
